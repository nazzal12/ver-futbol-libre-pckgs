## Developer packages — Futbol Libre Hoy

Offline-tested formatting helpers + online calendar client for the public feed  
`https://verfutbollibre.net/api/v1/calendar`.

| Platform | Directory | Package |
| --- | --- | --- |
| npm | `js/` | `futbol-libre-hoy` |
| PyPI | `python/` | `futbol-libre-hoy` |
| crates.io | `rust/` | `futbol-libre-hoy` |
| RubyGems | `ruby/` | `futbol-libre-hoy` |
| Packagist | `php/` (+ root `composer.json`) | `nazzal12/futbol-libre-hoy` |
| pub.dev | `dart/` | `futbol_libre_hoy` |
| Docker Hub | `docker/` | `nazzal12/futbol-libre-hoy` |

Quick start:

```bash
npx futbol-libre-hoy --live
# or
pip install futbol-libre-hoy && futbol-libre-hoy
```
