# Anchor text rules

When linking to the site in READMEs, listings, or descriptions:

- Use **one** link style per mention - never stack several keyword phrases in the same sentence.
- Rotate across assets (pick **one** per package README):
  1. Brand: `[Futbol Libre](https://verfutbollibre.net)`
  2. Single keyword: `[futbol libre en vivo](https://verfutbollibre.net)` **or** `[futbol en vivo hoy](https://verfutbollibre.net)` **or** `[Ver Futbol Libre](https://verfutbollibre.net)` - not more than one of these in the same file as a linked phrase.
  3. Naked URL only: `https://verfutbollibre.net` (no keyword wrap).
- Prefer brand or naked URL most of the time; keyword-rich anchors are the minority.
- Registry `homepage` / `repository` fields carry the canonical URL without needing keyword text.
